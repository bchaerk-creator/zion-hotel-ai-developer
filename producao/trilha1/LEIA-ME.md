# Trilha 1 · kit para o Claude Code

## Como usar
1. Descompacte este zip numa pasta do seu computador, por exemplo `Trilha1`.
2. Abra o Claude Code dentro dessa pasta. Ele lê o `CLAUDE.md` sozinho e já sabe o que fazer.
3. Escreva para ele: **"Leia o CLAUDE.md e comece pelo passo 1."**
4. Ele vai te perguntar qual voz usar, montar o primeiro vídeo do Marco Zero e te mostrar antes de seguir. Daí em diante, aula por aula.
5. No fim, a pasta `saida/CLICKMAX/` tem tudo organizado por módulo, com o `CHECKLIST.md` do que você faz no ClickMax.

## O que tem aqui
| Pasta | Conteúdo |
|---|---|
| `00-marco-zero/` | apresentação (49 slides) e roteiro + prompt dos 9 vídeos |
| `01-…` a `06-…` | por aula: e-book (PDF e HTML), apresentação em PDF e roteiro + prompt dos vídeos |
| `fotos/` | as 18 fotos reais da Zion usadas nos vídeos |
| `ferramentas/` | as 5 ferramentas da trilha: especificação, campos, contas já programadas e testes |
| `clickmax/` | como o curso fica no ClickMax: 7 módulos, 52 aulas em vídeo |
| `pendencias/` | o que ficou para você decidir em cada aula |

| Módulo | Vídeos | Ferramenta no fim |

## Antes de subir para os alunos
- Os vídeos vão para o YouTube (não listado), o Vimeo ou o Panda Video, e o link vai na aula do ClickMax.
- Troque `[domínio do app]` pelo endereço das ferramentas e `[link da página de inscrição]` (no pitch do Marco Zero) pelo link da oferta.
- Confira as pendências da pasta `pendencias/`.
