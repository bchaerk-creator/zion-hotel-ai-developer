# Subir os arquivos do Produto 06 na área de membros do ClickMax (10 minutos, só Bruno)

A API do ClickMax não aceita upload de PDF, vídeo nem planilha (o upload de mídia está desativado na conta: "Module disabled: social-posts:create"). A estrutura já está pronta; falta só arrastar cada arquivo para a aula certa.

**Onde:** ClickMax → Área de membros → portal **Zion Collection** (`zion-collection`) → curso → módulo → aula → editar → enviar arquivo ou vídeo.
